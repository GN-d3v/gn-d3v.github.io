# GN d3v — versione TypeScript

Copia del portfolio originale con menu mobile e modulo di contatto implementati in TypeScript. Richiede Node.js e npm.

```sh
npm install
npm run dev
```

Per creare la versione pronta per la pubblicazione: `npm run build`. Il risultato si trova in `dist/`; è questa cartella che va pubblicata. Il modulo usa lo stesso servizio e destinatario della versione originale.
